# OTHER

数学建模竞赛资料与论文存档仓库。

## 仓库内容

本仓库收录了近年数学建模相关赛事的题目原文与论文资料，供学习与参考。

| 文件 | 说明 |
| --- | --- |
| `2024年数模国赛.pdf` | 2024 年全国大学生数学建模竞赛赛题 |
| `2025年数模国赛.pdf` | 2025 年全国大学生数学建模竞赛赛题 |
| `2026年数模美赛.pdf` | 2026 年美国大学生数学建模竞赛（MCM/ICM）赛题 |
| `2025年揭榜挂帅-无人集群.pdf` | 2025 年"揭榜挂帅"无人集群专项赛题资料 |
| `2026论文-Model.pdf` | 2026 年建模论文（Model 部分） |

## 使用说明

- 直接点击文件名即可在 GitHub 上预览 PDF。
- 也可以 `git clone` 到本地后用任意 PDF 阅读器打开。

```bash
git clone https://github.com/bal483836-ctrl/other.git
cd other
```
